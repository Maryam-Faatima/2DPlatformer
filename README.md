🎮 2D Platformer Game (Unity)

A 2D platformer game developed using Unity, featuring multiple levels, enemy interactions, character selection, and immersive audio. This project focuses on smooth gameplay, polished mechanics, and engaging level design.

🕹️ Features

5 handcrafted levels

Enemy interactions and obstacles

Character selection system

Integrated sound effects and background audio

Smooth player movement and controls

🛠️ Tech Stack

Engine: Unity

Language: C#

Assets: Sprite pack from Unity Asset Store

Development: Animations, level design, gameplay logic implemented manually

🎯 What I Learned

Implementing core platformer mechanics

Level design and pacing

Working with animations and Unity physics

Structuring scalable and readable C# scripts
